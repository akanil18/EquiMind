# EquiMind v1.0: Structured Evidence Graph & Context Compression Engine

Trustworthiness requires that every statement generated by the AI must be traceable back to original evidence. Plain text observations are stored as structured `EvidenceNode` objects forming an Evidence Graph.

---

## 🧬 Evidence Node Provenance Schema (`equimind.evidence.schema`)

```python
class EvidenceNode(BaseModel):
    id: str                                  # Unique UUID
    source_type: EvidenceSource              # SEC filing, Bloomberg news, Reddit, Twitter, GitHub commits, etc.
    title: str
    content: str
    url: Optional[str]                       # Clickable primary proof link
    publication_timestamp: datetime          # Publication timestamp
    author: Optional[str]
    author_credibility: AuthorCredibility    # LOW, MEDIUM, HIGH, VERIFIED_OFFICIAL
    confidence_score: float                  # 0.0 to 1.0
    sentiment: SentimentPolarity             # VERY_BEARISH to VERY_BULLISH
    affected_ticker: str
    affected_sector: Optional[str]
    tags: List[str]
    supporting_references: List[str]
    metadata: Dict[str, Any]
```

### Relational Evidence Edges
`EvidenceGraph` connects nodes using relational directed edges: `SUPPORTS`, `CONTRADICTS`, `CORROBORATES`, `DERIVES_FROM`, `RELATED_TO`.

## ⚡ Non-LLM Deterministic Context Optimization & Compression Engine (`equimind.context.compressor`)

To prevent LLM context window overflow without spending extra API calls on summarization, `ContextCompressor` executes a 5-step deterministic in-memory pipeline:

1. **Temporal Cutoff Filtering**: If running in backtesting mode (`as_of_date`), prunes any node published after the cutoff.
2. **Exact Deduplication**: Computes MD5 normalized content hashes to remove duplicate observations.
3. **Fuzzy Similarity Clustering**: Computes Jaccard token set similarity ($\frac{|A \cap B|}{|A \cup B|}$) to group redundant news headlines or social posts across platforms, retaining the highest credibility node per cluster.
4. **Relevance & Time-Decay Ranking**: Calculates composite score $S$:
   $$S = \text{CredibilityWeight} \times \text{Confidence} \times e^{-0.05 \Delta t} \times \text{KeywordRelevance}$$
   where $\Delta t$ is age in days.
5. **Token Budget Packer**: Packs top-ranked, deduplicated evidence into the prompt context budget (~4 chars/token) up to `max_context_tokens`.
