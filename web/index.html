What Makes EquiMind Different

🚫🤖
Zero LLM Math
All financial calculations — RSI, Sharpe, Altman Z-Score, Piotroski F-Score, Monte Carlo, Portfolio Optimization — are computed 100% deterministically in Python. The LLM only synthesizes verified results.
⚔️
Adversarial Debate
BullAgent and BearAgent independently build opposing investment theses. JudgeAgent resolves contradictions, strips unsupported claims, and produces a transparent conviction score.
🔗
Full Evidence Provenance
Every claim in every report links back to its original source — SEC filings, earnings calls, Bloomberg news, Reddit posts, GitHub commits, or macroeconomic data. No hallucinations can hide.
🔌
Model Agnostic
Switch between OpenAI, Gemini, Claude, DeepSeek, Ollama, or the built-in Mock engine without changing any research logic. The orchestration layer is always in control.
🎯
Sector-Aware Planner
NVIDIA gets GPU shipments and GitHub commit velocity. Bank of America gets NIM and credit quality. The planner constructs unique research pipelines per company type — no fixed templates.
⏳
Time Machine Backtesting
Run any research query as if you were in January 2022. The TemporalGuard automatically blocks future data from contaminating historical analysis, enabling honest look-ahead-free backtesting.
